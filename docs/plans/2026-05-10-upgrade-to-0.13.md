## Summary of what upstream added (0.11–0.13)

Covered across three releases (~2500 commits). Highlights relevant to our fork:

- **0.11 (Interface):** Transport ABC (Anthropic / ChatCompletions / Responses / Bedrock), native NVIDIA NIM plugin, Ink-based TUI, `/steer`, shell hooks, orchestrator subagent role, expanded plugin surface.
- **0.12 (Curator):** Autonomous `hermes curator`, `hermes -z` one-shot mode, LM Studio first-class, pluggable gateway platforms, `redaction.enabled` default flipped to off.
- **0.13 (Tenacity):** Multi-agent Kanban, `/goal` Ralph-loop, Checkpoints v2, session auto-resume, 8 P0 security fixes (redaction back ON by default, Discord role-scoping, WhatsApp strangers rejected, MCP OAuth TOCTOU), `no_agent` cron mode, `ProviderProfile` plugin ABC, `allowed_{channels,chats,rooms}` across platforms, `[[as_document]]` skill directive, `transform_llm_output` plugin hook.
